# Interval Timer Clock

An iOS app for interval training with customizable sets and rest periods.

## Features

- **Customizable Timers**: Create interval timers with custom work and rest periods
- **Standard Mode**: Set up timers with consistent interval durations
- **Custom Mode**: Configure each interval individually with different durations, names, and colors
- **Save and Reuse**: Save your favorite timer configurations for future use
- **Visual Feedback**: Color-coded display shows current interval status
- **Audio Alerts**: Sound notifications for interval transitions
- **Timer Templates**: Pre-configured templates for common workout types

## How to Use

1. Create a new timer by tapping the "+" button 
2. Set up intervals:
   - Add preparation time
   - Configure work intervals
   - Set rest periods between intervals
3. Save your timer with a custom name
4. Start your workout!

## Example Timer Configurations

- **Tabata Workout**: 20 seconds of high-intensity work followed by 10 seconds of rest, repeated 8 times
- **5x5 Strength Training**: 5 sets of 3-minute work intervals with 90-second rests
- **Custom Circuit**: Configure your own sequence of intervals with different durations and rest periods

## Technical Details

- Built with SwiftUI and SwiftData
- Uses MVVM architecture
- Native iOS notifications and sounds
